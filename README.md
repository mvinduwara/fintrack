# FinTrack

## Description
FinTrack is a comprehensive full-stack personal finance tracker designed to help users seamlessly manage accounts, track transactions, set budgets, and monitor financial goals and investments. 

## Tech Stack

### Frontend
* **Framework:** React 18 (TypeScript)
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **State Management:** Zustand
* **Routing:** React Router v6

### Backend
* **Runtime & Framework:** Node.js with Express.js
* **ORM:** Prisma
* **Database:** PostgreSQL
